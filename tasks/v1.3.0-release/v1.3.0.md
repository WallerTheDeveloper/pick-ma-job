# v1.3.0

1. Do not evaluate jobs until user specifically asks for it. If user clicks on evaluate job - then evaluation must start. For this feature add button in the result row “Evaluate job” which will trigger AI job evaluation
2. If job is in language that user doesn’t speak - skip it. AI must match languages that user speaks from profile and check whether job description is in language that user speaks. If not - then skip it.
3. AI CV generation tend to lie too much when customizing CV. It lied about user’s French language proficiency which is unexeptable. 
4. When customizing CV - generate only text that needs to be changed. Do not generated text that is the same as original. The idea is to save tokens usage and make generation cheaper. For example phone number never change but summary usually is something that needs to be changed. The only expeception is title of the section - it must be always generated no matter whether it’s the same as original or not.
5. If job is no longer accepting applications - ignore it (check if scraper provides this data). 
6. Every account’s profile must be treated as unique and not as developer. For example person looking for job can be HR or any other speciality. Not just IT sphere. The idea of this platform is too provide easier search for any person - no matter what speciality they are.
